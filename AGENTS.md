# AGENTS

## Git Branching

- Create every new feature, enhancement, fix, or custom version on a branch prefixed with `vin/`.
- Name branches `vin/<feature-slug>` or `vin/<type>-<feature-slug>`, such as `vin/feat-presensi-api` or `vin/fix-auth-token`.
- Create and switch to the branch before editing. Do not commit new work directly to `main` unless explicitly instructed.
- Push new branches with `git push -u origin vin/<feature-name>`.
